# Flask Todo App

A simple and responsive Todo Web Application built using Flask, SQLAlchemy, Bootstrap, and SQLite.

## Features

- Add new todos
- Update existing todos
- Delete todos
- Responsive Bootstrap UI
- SQLite database integration

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- Bootstrap 5
- HTML/CSS

## Installation

Clone the repository:

```bash
git clone https://github.com/rahulchaudhary4490-spec/flask-todo-app.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Flask app:

```bash
python app.py
```

Open in browser:

```bash
http://127.0.0.1:5000
```
